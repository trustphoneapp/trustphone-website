What TrustPhone Does

Practical tools for
safer decisions

Current security analysis stays on your phone. TrustPhone explains warning signs so that you can decide what to do next.

Optional Notification Access
🔍

Multi-stage notification review

When you enable Notification Access, TrustPhone reviews notification previews locally for warning signs such as urgency patterns, suspicious links, and related context across messages from the same sender. Notification text is not uploaded.

✅

Sender-source checks

Checks whether messages claiming to be from known sources match TrustPhone's locally stored sender information. This is a helpful review signal, not a guarantee.

📦

Review newly installed apps

See where an installed app came from, the access it may use, and signals worth reviewing in plain English.

🗂️

APK file check

Inspect an APK file before installing it. TrustPhone shows requested permissions, file details, and warning signs to help you decide.

🌐

Turn off unwanted website notifications

Follow a simple guide to review and turn off website notifications that you do not recognize.

🔒

Encrypted local storage

Warning history is stored locally in an encrypted SQLCipher database. Alert history auto-deletes after 7 days, sender history after 90 days. You can clear it anytime.
